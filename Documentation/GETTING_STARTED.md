# V2.0 集中使用说明

本说明面向日常使用。Release 只提供一个 `AOA_System_V2.0.zip`；原始 ADC 查看器不在部署包中，原始工程和开发工具在 GitHub 源码目录中。

## 部署包内容

```text
AOA_System_V2.0/
  start_pc.cmd              唯一上位机启动入口
  PC/                       页面、配置及内部归档/回放支持
  runtime/python/           电脑运行环境
  common/                   共用的数据处理工具
  Board/V2.0.tar.gz          复旦微运行文件、模型、PL 和依赖
  FPGA7100/BOOT.bin          7100 启动镜像
  Documentation/            集中说明
```

整体保留在一个文件夹中，不单独移动 `PC/`、`runtime/` 或 `common/`。普通使用不需要安装 Python、pip，不需要登录、令牌或外网资源。

## 日常启动

1. 连接六路接收链、7100、复旦微和电脑的设备网络；确认公共本振锁定。
2. 给设备上电。安装完成的复旦微自动加载 PL，并启动 V2.0 采集服务。
3. 双击 `start_pc.cmd`，打开启动窗口显示的网页地址。默认网页端口为 `8775`；占用时自动选择空闲端口。
4. 检查网页的连接状态、采集批次和数据更新时间，再开始测量。

默认设备地址只是现场可修改的配置：复旦微遥测端口为 `9000`，7100 采集端口为 `7`。正常采集由复旦微统一请求 7100，电脑接收复旦微推送的结果，不直接争抢 ADC 采集。

多台电脑可同时运行同一份上位机，查看相同批次。现场约定一人发送模式和波束控制命令，其他人只查看。

## 模式和操作

| 控制项 | 用途 |
|---|---|
| POSITION | 两组三天线 ML 交叉定位；在有效交点中按路径能量选点。 |
| ANGLE | 六路 ML 候选与同批 CBF 空间谱软匹配，输出选中的 ML 路径角。 |
| LOCATE | 进行测量，不提交 NPU 识别任务。 |
| IDENTIFY | 同样采集四帧，同时将 PL 合成 I/Q 交给 NPU 识别。 |
| 手动波束 | 滑条和输入框只更新预览，点击 APPLY 后才下发 PL。 |
| 波形、频谱 | 两个独立上报开关，识别模式不会自动打开。 |
| 调试归档回传 | 默认关闭，调试时才开启。 |

ANGLE 与 POSITION 相互独立。POSITION 不使用六天线联合角牵引交点选择。识别支持 FM、AM、CW、NOISE、OOK、PM；历史识别不会冒充本批结果。

## 调试归档与保存位置

**正常测量保持调试归档关闭。** 关闭时不生成新的原始归档，不进行后台打包、文件校验和后续原始数据发送；测量结果正常更新。已发出的单个网络请求最多等待 3 秒，未确认原件暂停在有容量上限的板端 RAM 中，重新开启后可续传。

需要复现问题时开启开关，等待板端确认。原始 ADC、PL 输出与同批 PS 结果保存到电脑，长期数据不存板端。波形和频谱仍由各自开关控制。

| 内容 | 电脑文件夹内的位置 |
|---|---|
| 默认配置 | `PC/settings.json` |
| 本机覆盖配置 | `PC/local_config/settings.json` |
| 上位机日志 | `PC/local_config/logs/` |
| 原始归档 | `PC/data/hardware_7100/board/` |

相对数据路径以 `PC/` 为基准。归档接收默认端口为 `7012`；同一配置可复用已运行的接收器，冲突时选择空闲端口。停机前如需保留未确认的调试数据，应先等待其接收确认。

## 首次安装或更新复旦微

已经安装并能自动采集的设备可跳过本节。以下 `BOARD_IP` 需替换为现场复旦微地址。更新前停止采集，把需保留的旧工程备份到电脑，不在板上累积备份。

在电脑部署包目录执行：

```sh
scp Board/V2.0.tar.gz root@BOARD_IP:/tmp/aoa-v2.tar.gz
ssh root@BOARD_IP
```

在复旦微 SSH 中执行：

```sh
systemctl stop aoa-v2.service
mkdir -p /root/aoa_system/V2.0
tar -xzf /tmp/aoa-v2.tar.gz -C /root/aoa_system/V2.0
cd /root/aoa_system/V2.0
./install_service.sh
./start.sh
./status.sh
rm /tmp/aoa-v2.tar.gz
```

旧版本文件应在电脑备份完成后移出安装目录，再解压新包，避免残留文件混入。运行包只包含必要程序、模型、PL、配置和应用依赖，不把上位机、源码、训练集或测试放到板端。

`aoa-pl.service` 先准备 PL，`aoa-v2.service` 再启动采集；安装服务后支持上电自动运行。SSH 中手动操作统一使用：

```sh
cd /root/aoa_system/V2.0
./start.sh
./status.sh
./stop.sh
```

7100 的 `BOOT.bin` 用于现有启动介质更新；具体写入位置和启动开关应遵循该板原有方式，不把复旦微运行包写入 7100。

## 排查入口

- 网页不更新：检查复旦微服务状态、设备网络地址及采集批次是否变化。
- 看到了历史识别：确认已切换到 IDENTIFY，并等待当前批次推理完成。
- 调试回传较慢：正常测量关闭归档；需要调试时再开启。
- 更换阵列或接收链：核对阵列配置、通道顺序和独立补偿文件。

构建、算法和数据格式细节集中在同目录其他文档，不需要日常操作人员逐份阅读。
