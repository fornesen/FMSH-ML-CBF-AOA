# 数据链路

```text
六天线 → 共用本振下变频 → 三块双通道 ADC → 7100 缓存/网口
  → 复旦微 PS：12 位符号恢复、逐路去直流
  → PL：DDC、滤波抽取
      ├─ 六路独立 I/Q → 零64点/Hann4032 → FFT4096 → PS 测角/定位
      └─ 六路移相合成 → PHA I/Q4096
            ├─ PS 观测波形/复频谱
            └─ 四帧 IPC → PS 特征处理 → NPU 调制识别
  → 同批结果遥测 → 多台电脑上位机
```

## 7100 与输入适配

每次 `START` 返回 16384 组、六通道、little-endian uint16 容器，共196608字节。容器低12位是 ADC 二进制补码，高4位为零。通道顺序为 CH0～CH5。

PS 按12位恢复为有符号值并扩展至16位，然后逐通道减去当前帧舍入后的均值。原始网络数据与实际送 PL 的去直流输入分别保留，不能以处理后数据覆盖原件。

默认 ADC 采样率100 MS/s，一帧覆盖163.84 μs。请求之间有间隔，四帧不能当成连续采样流。硬件协议没有独立物理帧号；批次关联由 PS 的串行请求、轮次顺序与完整性检查建立。

只有复旦微向7100发正式采集请求。电脑独立 ADC 查看器会直接请求7100，须与正式采集互斥使用。

## PL 的两条分支

DDC 和 FIR 抽取后默认得到25 MS/s复数 I/Q。外部下变频的本振与 PL DDS 是两个不同频率参数。示例RF445 MHz、本振433 MHz得到12 MHz实中频；DDS12.5 MHz时，所用正频分量在复基带约为−0.5 MHz。改变RF时应同步调整DDS与搜索带，不能只改显示载频。

### 六路 ML FFT

正式PL版本为 `0x00010001`，连接为六路FIR/FIFO、帧复用、FFT窗、FFT结果槽。每通道4096点：

- 第0～63点I/Q置零，保留原时间位置。
- 第64～4095点乘4032点周期Hann窗。
- 输出4096点FFT，不压缩成4032点，不跨帧补样本。

PS直接解码、按窗系数和归一化并应用通道补偿，不再做IFFT、第二次加窗或FFT。旧PL `0x20261020` 与历史无头记录有显式软件预处理兼容入口，必须按记录的格式选择，不能仅凭文件长度推断。

每批固定四轮独立FFT。四帧平均功率选同一组频点，再做批次内协方差融合。ANGLE和POSITION的选择分别见[算法](ALGORITHMS.md)。

### 波束合成 PHA

移相合成支路独立于六路FFT窗。每轮保留4096个signed32小端I/Q，四轮总计131072字节；原PHA包含启动段。

| 消费者 | 处理 |
|---|---|
| 原始归档 | 保存完整PHA，不改启动段。 |
| 波形显示 | 从前64点之后选择4032、1024或512点显示。 |
| PS观测频谱 | 工作副本前64点置零，后4032点周期Hann，完整4096点复FFT。 |
| NPU | 每轮只丢弃一次前64点，对4032点做特征处理，不跨轮拼STFT窗。 |

观测频谱保留4096个双边频点，频点间隔为25 MHz / 4096，约6.104 kHz。相对功率以当前全谱最大值归一化；保留稳定段的DC。边界频点隐藏仅改变绘制，不改变计算或原始数据。

## 四帧、IPC 与识别

LOCATE和IDENTIFY均采集四帧。LOCATE不交付NPU；IDENTIFY在四轮完整后尝试发布同批PHA。消费者忙或未运行时跳过交付，不覆盖其正在处理的数据，不补发旧批次。

PS和NPU通过单槽POSIX共享内存交接，状态为IDLE、WRITING、READY、BUSY。发布与推理是不同事件；`sent`不代表识别完成。NPU硬件阶段与采集硬件阶段使用同一设备互斥，CPU算法与网页收发不因此持锁。两进程常驻不表示它们可以同时访问共享DMA/DDR。

识别结果带采集批次和模型身份。上位机只把身份匹配的结果关联到该批；较早结果明确显示为历史识别，不替代本批失败或未提交任务。

## 上位机和调试归档

上位机订阅复旦微推送的同一份遥测，不在电脑重选在线测角/定位答案。连接时登记本机归档接收端；多台电脑可同时查看，控制以板端回执为准。

调试归档关闭时不生成新的ADC/PL归档，不继续压缩、校验或上传原件。开启后才将原始ADC、PL输入/输出、PHA与最终PS结果配对传到电脑。未确认数据只在有界RAM暂存；电脑持久保存并确认后释放。关闭时暂停待发任务，已发请求最多等待3秒，重新开启可继续。格式和回放见[归档与回放](RECORDING_AND_REPLAY.md)。
