# 通道配置与补偿

部署包已经携带当前阵列和通道补偿文件，日常启动不需要重新校准。

## 配置位置

源码配置在 `Board/config/`，板端对应 `/root/aoa_system/V2.0/config/`。`job.json` 指定阵列文件、补偿文件、RF 频率和处理参数。补偿是独立文件，不固化进算法。

- 几何坐标：沿阵列 X 轴，正前方 +Y 为 0°，角度向 CH5 一侧为正。
- 通道顺序：ADC1→CH0/CH1、ADC2→CH2/CH3、ADC3→CH4/CH5；每块 AD1 在前、AD2 在后。
- 射频波长由 RF 频率计算；外部混频本振和内部 DDS 分别按真实链路配置。
- 补偿只应用一次。六路 ML/CBF 使用校正后的 FFT；实际 PL 波束寄存器由对应控制流程生成。

## 校准操作

更换 ADC、混频器、线缆、天线位置或公共本振链后，需要重新检查通道一致性。保留有效补偿文件，采集新的参考后再替换；不把调试报告作为运行配置。

板端独立交互程序在 SSH 中运行，先停止正式采集：

```sh
cd /root/aoa_system/V2.0
./stop.sh
./python.sh calibration/calibrate.py --help
```

根据程序参数选择测量方式。现场坐标按实际位置输入，默认值不代表已经测量。位置、朝向、参考频率和接收链应在一次标定中保持可追溯；校准结果回到电脑检查后，再更新独立补偿文件并恢复服务。

近距离空口标定同时含传播、天线和接收链影响，不能把所有误差都解释为固定线缆延迟。频段补偿以当前测量频段的数据为依据。
